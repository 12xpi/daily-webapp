# Схема ID для ссылок на текст «Этики» (data/ethics.json)

Этот файл не используется приложением напрямую — это памятка для вас,
чтобы знать, как писать ссылки вида {{ID}} в других файлах данных
(step_prayers.json, reflections.json, prayers.json, glossary.json).

## Общий вид ID

    <номер_части><тип><номер>[<суффикс>]

Часть — всегда первая цифра (1–5), соответствует части «Этики»
(I–V). Дальше — буквенный код типа блока, затем порядковый номер
внутри части (считается по порядку появления в тексте, а не по
цифре, напечатанной в конкретном издании — в паре мест у Спинозы
нумерация в оригинале сбивается, поэтому здесь используется
сквозной счёт).

## Коды типов

| Код     | Тип блока                          | Пример   |
|---------|-------------------------------------|----------|
| d       | Определение                         | 1d6      |
| affd    | Определение аффекта (Часть III)     | 3affd12  |
| ax      | Аксиома                             | 1ax1     |
| lem     | Лемма (физическая вставка, Часть II)| 2lem3    |
| post    | Постулат                            | 2post1   |
| p       | Положение (теорема)                 | 1p11     |
| app     | Приложение (к части)                | 1app     |
| pref    | Предисловие                         | 3pref    |
| gad     | Общее определение аффектов          | 3gad     |

## Подпункты положений/определений

Прикрепляются к ID своего "родителя" (обычно — положения):

| Суффикс | Значение         | Пример       |
|---------|------------------|--------------|
| dem     | Доказательство   | 1p11dem      |
| cor     | Королларий       | 1p13cor      |
| cor2    | Второй королларий (если их несколько) | 1p13cor2 |
| schol   | Схолия           | 1p15schol    |
| schol2  | Вторая схолия    | 1p15schol2   |
| expl    | Объяснение       | 1d6expl      |

## Примеры готовых ссылок

- Определение Бога (Часть I, Определение VI):        `{{1d6}}`
- Объяснение к этому определению:                     `{{1d6expl}}`
- Положение о единственности субстанции (Ч.I, Полож.14): `{{1p14}}`
- Схолия к этому положению:                            `{{1p14schol}}`

## Как проверить точный ID нужного места

Откройте data/ethics.json и найдите нужный отрывок по тексту —
у каждого блока есть поле "label" (человекочитаемая подпись, например
"Определение VI") и поле "id" — именно "id" и нужно подставлять
в фигурные скобки {{...}} в текстах других файлов.
